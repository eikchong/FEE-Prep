# FEE 2027 (Civil) Prep

Personal Streamlit study site for the PEB Singapore **Fundamentals of Engineering Examination (Civil)**,
Wed 6 Jan 2027. Single user, runs locally.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Optional OCR for scanned notes: install Tesseract (`brew install tesseract` / `apt install tesseract-ocr`).
Without it, scanned pages are indexed with `ocr=true` but no text.

## Streamlit Community Cloud
Deploy from this repo with main file `app.py`. `packages.txt` installs Tesseract for OCR.
⚠ The Cloud filesystem is **not persistent**: `data/progress.json`, the Library index and uploaded
materials reset whenever the app reboots or redeploys. Use it for browsing/drilling for now; keep real
progress on a local run until `utils/storage.py` is pointed at SQLite/Supabase. Set the app to private
(Settings → Sharing) so only you can edit it.

## Study materials
Drop files into `materials/CE101 … CE206/`, `_general/` or `_unsorted/` (.pdf .docx .pptx .md .txt .png .jpg),
then click **Re-scan** in the Library (or run `python scripts/ingest.py`). Prefix a filename with a sub-topic id
(`CE201-10_slender-columns.pdf`) to force that tag. Synonyms for auto-tagging live in
`data/topic_keywords.json`; manual tags in the UI always win and survive re-scans. `materials/` is git-ignored.

## Data
- `data/syllabus.json` — generated by `scripts/build_syllabus.py` (ids are stable: only append sub-topics)
- `data/mcq_bank.json`, `data/part2_bank.json` — original questions; every number recomputed in `tests/test_banks.py`
- `data/progress.json` — your progress (git-ignored). `utils/storage.py` is the only persistence layer, so it can be
  swapped for SQLite/Supabase later.
- `data/library.db` — SQLite + FTS5 index of `materials/` (rebuildable).

Set `FEE_DATA_DIR` / `FEE_MATERIALS_DIR` to point elsewhere (the tests do this).

## Tests
```bash
python -m pytest -q
```
Covers calculators vs hand-worked examples, every bank answer, planner rules (never on/after exam day,
last 7 days mocks), storage round-trip, library ingest/search/tagging/coverage, PDF export, and a smoke
render of every page.

## Code notes
Eurocode notation, SI units. Nationally Determined Parameters (αcc, γM2, K′, LTB method…) are flagged
"verify against Singapore NA" — the defaults are recommended EN / common UK-NA values.
